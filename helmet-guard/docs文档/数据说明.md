> ⚠️ **原始压缩包是唯一的离线备份，禁止删除、覆盖或移动。**
> 任何解压操作都必须写入**全新的空目录**，绝不允许覆盖 `helmet-guard/dataset/`。

## 二、目录结构

```
helmet-guard/dataset/                     ← 不入 Git（.gitignore 排除）
├── ebike_helmet_v2/
│   ├── data.yaml
│   ├── README.dataset.txt
│   ├── README.roboflow.txt
│   ├── train/{images,labels}/
│   ├── valid/{images,labels}/            ← 注意：目录名是 valid
│   └── test/{images,labels}/
└── roboflow_motorcycle/
    ├── data.yaml
    ├── README.dataset.txt
    ├── README.roboflow.txt
    ├── train/{images,labels}/
    ├── valid/{images,labels}/
    └── test/{images,labels}/
```

每个 `labels/` 目录内是与 `images/` 同名的 `.txt` 文件（一一对应），外加一个
`labels.cache` —— 后者是 YOLO 训练时生成的标签缓存索引，**可随时重新生成**，
不属于数据本体，不纳入版本控制。

## 四、类别映射

映射关系由 `scripts/audit_dataset.py` **从标签文件实际内容统计核实**，
并在各 `data.yaml` 顶部以注释形式固化。

### `ebike_helmet_v2`（3 类）

| 类别 id | 类别名 | 全库实例数 | 含义 |
| ---: | --- | ---: | --- |
| 0 | `Cyclists` | 7,180 | 骑行者 / 电动车框 |
| 1 | `helmet` | 7,545 | 已佩戴头盔的头部 |
| 2 | `no helmet` | 5,261 | 未佩戴头盔的头部 |

**结构特征**：class 0（骑行者框）与 class 1/2（头部状态）可在同一张图中共存 ——
train 中有 1,688 张图含多个不同 class id，824 张图同时含 0/1/2。
推理时可用 class 0 定位骑行者 ROI，再在 ROI 内用 class 1/2 判定头部状态。

### `roboflow_motorcycle`（2 类）

| 类别 id | 类别名 | 全库实例数 | 含义 |
| ---: | --- | ---: | --- |
| 0 | `helmet` | 1,765 | 已佩戴头盔的头部 |
| 1 | `no helmet` | 854 | 未佩戴头盔的头部 |

**结构特征**：**没有**骑行者框类。单图可同时标注多个头部
（train 中仅含 class 0 的 765 张、仅含 class 1 的 213 张、混合 126 张）。

> ⚠️ **两个数据集的类别 id 不可互换**：`ebike_helmet_v2` 的 class 0 是骑行者框，
> `roboflow_motorcycle` 的 class 0 是「已戴头盔」。合并训练前必须做 id 重映射。

### 标签文件格式

每行一个目标实例，字段以空格分隔：

```
<class_id> <x_center> <y_center> <width> <height>
```

后四个值是**归一化坐标**（中心点 + 宽高，取值范围 `[0, 1]`）。
审计已确认全库无坐标越界、无类别 id 越界、无格式非法行。

## 五、如何从原始 zip 重建数据集

> 以下步骤仅在**本地数据集确实缺失**时才需要执行。
> **绝不允许**在 `helmet-guard/dataset/` 已存在的情况下运行解压 —— 那会覆盖完好数据。

### 前置检查（必做）

```powershell
# 确认原始 zip 存在且数据集当前状态
Get-ChildItem "E:\AI办公比赛\bisai\数据集" -File
Get-ChildItem "E:\AI办公比赛\bisai\helmet-guard\dataset" -Directory
```

若 `helmet-guard/dataset/` 下**已存在** `ebike_helmet_v2/` 或 `roboflow_motorcycle/`，
说明数据完好，**立即停止**，不要执行任何解压。

### 重建步骤

```powershell
# 1. 解压到全新的临时目录（绝不用 dataset/ 作为解压目标）
$stage = "E:\AI办公比赛\bisai\.dataset_stage"
New-Item -ItemType Directory -Force $stage | Out-Null
Expand-Archive -Path "E:\AI办公比赛\bisai\数据集\-------2023-3-19.v2i.yolov8.zip" `
                -DestinationPath "$stage\ebike_helmet_v2" -Force
Expand-Archive -Path "E:\AI办公比赛\bisai\数据集\Motorcycle helmet.v1-helmet_detection_v1.yolov8.zip" `
                -DestinationPath "$stage\roboflow_motorcycle" -Force

# 2. 检查解压结果（Roboflow 导出通常多一层同名目录）
Get-ChildItem "$stage\ebike_helmet_v2" -Recurse -Directory -Depth 1

# 3. 仅在 dataset/ 下对应目录不存在时，才移动过去
$target = "E:\AI办公比赛\bisai\helmet-guard\dataset\ebike_helmet_v2"
if (-not (Test-Path $target)) {
    Move-Item "$stage\ebike_helmet_v2\*" $target
}

# 4. 清理临时目录
Remove-Item -Recurse -Force $stage
```

### 重建后必须验证

```powershell
cd E:\AI办公比赛\bisai\helmet-guard
python scripts/audit_dataset.py
```

审计报告应显示图片与标签一一对应、数量与本文件第三节一致。

## 六、数据版本管理方案

### 当前方案：Git 排除 + 文档记录 + 内容哈希审计

| 数据 | 体积 | 处置 | 理由 |
| --- | ---: | --- | --- |
| `helmet-guard/dataset/` | 2,945 MB | `.gitignore` 排除 | 远超 Git 合理纳管体积 |
| `数据集/`（原始 zip） | 2,946 MB | `.gitignore` 排除 | 同上，且是离线备份 |
| `*.cache` | 极小 | `.gitignore` 排除 | YOLO 生成的缓存索引，可重建 |
| 数据集元信息 | 极小 | **入库** | `data.yaml` 注释 + `docs文档/数据说明.md` + 审计报告 |

### 为什么不启用 Git LFS

Git LFS 单文件上限通常为 2 GB，而 `-------2023-3-19.v2i.yolov8.zip` 为 **2,830.6 MB**，
已超过单文件上限；即使分片，整套 2.9 GB 数据入库也会显著拖慢克隆与 CI。
因此维持 `.gitignore` 排除，通过**文档 + 审计报告 + 离线 zip 备份**三条途径保证可复现。

### 替代获取途径

若原始 zip 遗失，可从 Roboflow Universe 重新下载（链接见第一节）。
重新下载后**必须**运行 `scripts/audit_dataset.py` 核对数量是否与第三节一致。

## 七、`dataset/` 只读保护约定

`helmet-guard/dataset/` 内的文件**一律视为只读**。

| 规则 | 说明 |
| --- | --- |
| 训练脚本不得写入 | `dataset/` 下的任何文件都不应被训练流程改写 |
| CI 脚本不得写入 | CI 只做审计与冒烟测试，不得触碰数据 |
| `.cache` 属正常副作用 | YOLO 训练会在 `labels/` 下生成 `labels.cache`，允许出现但不入库 |
| 审计脚本严格只读 | `scripts/audit_dataset.py` 唯一写操作是输出到 `docs文档/` |
| 原始 zip 禁止删除 | `数据集/*.zip` 是唯一离线备份，任何情况下不得删除或覆盖 |

### 强制校验：训练冒烟测试

训练前建议先跑 1 个 epoch 的冒烟测试，确认 YOLO 能正确读取 `data.yaml`：

```powershell
cd E:\AI办公比赛\bisai\helmet-guard
python -c "
from ultralytics import YOLO
m = YOLO('yolov8n.pt')
m.train(data='dataset/ebike_helmet_v2/data.yaml', epochs=1, batch=4, workers=0,
        device='cpu', project='runs/p0_4_smoke', name='ebike_smoke',
        exist_ok=True, plots=False)
"
```

> 注意：ultralytics 会把 `project` 解析到 `runs/detect/` 之下，
> 实际产物路径为 `runs/detect/<project>/<name>/`。
> `project` 请用**新建**的名字，避免覆盖既有的 `runs/detect/*` 实验目录。

- 权重输出到 `runs/`，**不会覆盖**任何既有权重（`runs/` 本身也被 `.gitignore` 排除）。
- 本命令会生成 `labels.cache`，属预期副作用。
- 已实测通过：train 扫描 1930 张（127 backgrounds）、valid 扫描 467 张（22 backgrounds），
  与审计报告的空标签统计完全一致。
